# Security Policy

## Security Scrubber & Confidentiality Rules
SIMS1337 includes `GitSecurityScrubber.java` which automatically scans and redacts:
- OAuth tokens (`ghp_...`)
- GitHub Personal Access Tokens (`github_pat_...`)
- Gmail App Passwords
- API secrets
