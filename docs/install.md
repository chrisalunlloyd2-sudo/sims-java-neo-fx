# Installation & Setup Guide

## Requirements
- **Java JDK**: 17+ or 21 (`choco install openjdk17`)
- **Ollama**: Latest (`ollama.com`)
- **Python**: 3.11+

## Steps
1. Clone repository:
   ```bash
   git clone https://github.com/chrisalunlloyd2-sudo/sims-java-neo-fx.git
   cd sims-java-neo-fx
   ```
2. Compile JavaFX GUI source:
   ```bash
   mvn compile
   ```
3. Run GUI:
   ```bash
   mvn javafx:run
   ```
