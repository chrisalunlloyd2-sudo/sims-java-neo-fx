# Frequently Asked Questions (FAQ)

### What is SIMS1337?
SIMS1337 is a sovereign neuromorphic operating system where 37 local SLMs operate continuously on a 4D hex grid with real-time viscoelastic stress/strain physics.

### Does it require a GPU?
No, lightweight SLMs (`qwen2.5:0.5b`, `tinyllama:1.1b`) run efficiently on CPU or GPU.

### How does Cellular Microphone Gating work?
CMG enforces a single-speaker lock so only one model resides in VRAM at a time.
