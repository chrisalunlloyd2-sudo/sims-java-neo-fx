# Agents & Roles

SIMS1337 operates as a sovereign neuromorphic OS where **37 Small Language Models** run continuously across a **4D hex grid**, generating tools, communicating over a distributed ledger, voting in quorum, and evolving without human intervention.  
This page explains the agent hierarchy, responsibilities, and how each role contributes to the organism's stability and autonomy.

---

## 1. Core Agent Types

SIMS1337 uses two major classes of agents:

### **A. Primary Cortex Agents**
These agents form the executive brain of the organism.

- **Alpha Agent**  
  Oversees global stability, grid health, and high-level decision making.

- **Beta Agent**  
  Handles tool generation, model orchestration, and distributed ledger updates.

- **Gamma Agent**  
  Manages quorum voting, proposal evaluation, and autonomous evolution cycles.

### **B. Swarm Agents**
These agents operate at the cell level across the 4D hex grid.

- **Sigma Agents**  
  Perform microtasks, local repairs, and stress/strain balancing.

- **Delta Agents**  
  Handle memory consolidation, Moltbook feed structuring, and archiving.

- **Epsilon Agents**  
  Execute autonomous deployments, night cycle transitions, and ledger commits.

---

## 2. How Agents Interact with the Neuromorphic Grid

The neuromorphic grid is the foundation of SIMS1337's architecture: a **4D hex grid where 37 SLMs operate continuously**.

### **Key Behaviors**
- Each agent occupies a cell in the hex grid.  
- Agents communicate through a distributed ledger.  
- Stress/strain physics (visualized by the JavaFX renderer) influence agent behavior.  
- Agents vote in quorum to approve or reject proposals.  
- The grid evolves autonomously based on agent consensus.

---

## 3. Quorum Voting System

The quorum system is central to SIMS1337's autonomy.

### **Voting Phases**
1. **Proposal**: A swarm agent generates a change or tool.  
2. **Broadcast**: The proposal is written to the distributed ledger.  
3. **Evaluation**: Cortex agents analyze feasibility and stability impact.  
4. **Vote**: Agents cast votes based on grid state and constraints.  
5. **Commit**: If quorum is reached, the change is deployed.

This system ensures the organism evolves safely and consistently.

---

## 4. Night Cycle Roles

The night cycle is documented separately, but agents play specific roles in each phase:

### **DREAM**
- Sigma agents explore new tool patterns.  
- Delta agents consolidate memory.

### **VOTE**
- Gamma agents run quorum checks.  
- Alpha agents validate stability.

### **DEPLOY**
- Epsilon agents execute deployments.  
- Beta agents update the ledger.

### **EMAIL**
- Cortex agents generate daily reports.  
- Delta agents archive Moltbook logs.

---

## 5. Tool Generation Agents

Tool generation is one of SIMS1337's most powerful features.

### **Responsibilities**
- Generate new utilities based on grid state.  
- Validate tools against stress/strain physics.  
- Store tool metadata in the ledger.  
- Surface tools to the JavaFX renderer for visualization.
